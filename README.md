# 🏠 House Price Prediction using Machine Learning

This project predicts house prices using a real-world dataset from Kaggle. It demonstrates end-to-end machine learning workflow including data preprocessing, visualization, model building, and evaluation.

---

## 🚀 Google Colab

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/18o6sEoNUhuNPEN1a0Ze1QzG0P_apab1K?usp=sharing)

---

## 📊 Dataset

- Source: Kaggle Housing Dataset  
- Features: area, bedrooms, bathrooms, stories, parking, etc.  
- Target Variable: Price  

---

## 🧠 Features of Project

- Data preprocessing and feature encoding  
- Exploratory Data Analysis (EDA)  
- Linear Regression model implementation  
- Model evaluation using Mean Absolute Error  

---

## 🛠️ Tech Stack

- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Matplotlib  

---

## 📈 Model Performance

- Evaluated using Mean Absolute Error (MAE)  
- Demonstrates accurate prediction of housing prices  

---

## 💡 Conclusion

This project highlights how machine learning can be used to solve real-world problems like house price prediction using structured data.
